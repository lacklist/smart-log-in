# Session Workspace — облачный пилот

Расширение Chrome/Chromium и API для закрытого пилота на Windows и Linux. API хранит отдельный зашифрованный снимок на кабинет; шифрование и расшифровка выполняются расширением. В комплект входят PostgreSQL, HTTPS через Caddy и Docker Compose.

## Что нужно для запуска

- Linux VPS с публичным IPv4/IPv6, минимум 2 ГБ RAM и 20 ГБ диска.
- Домен или поддомен, DNS `A`/`AAAA` которого указывает на VPS.
- Открытые входящие порты TCP 80/443 и UDP 443.
- Docker Engine с Docker Compose plugin.
- Chrome/Chromium на клиентских устройствах.

Сервер не может автоматически завершить первоначальные проверки Google, VK или МИРЭА. Пользователь вручную входит в сайты на своём исходном устройстве, сохраняет снимок, а затем пробует перенести его на другое устройство. Сайты могут отклонить перенос или снова запросить проверку.

## Развёртывание на VPS

1. Скопируй всю папку `session-workspace-mvp` в отдельный каталог на VPS, например `/opt/session-workspace`. Не копируй `.env` в Git и не публикуй его.
2. Создай `.env` на VPS из `.env.example`. Укажи домен API и сгенерируй два разных длинных случайных секрета для пароля PostgreSQL и кода приглашения. В Ubuntu можно получить каждый секрет командой `openssl rand -hex 32`.
3. Сначала запусти только базу:

   ```bash
   docker compose up -d db
   ```

4. На первом клиентском компьютере загрузи эту папку расширения через `chrome://extensions` → режим разработчика → **Загрузить распакованное расширение**. На карточке расширения скопируй ID вида `abcdefghijklmnopqrstuvwxyzabcdef`.
5. В `.env` задай `ALLOWED_ORIGINS=chrome-extension://<ID_РАСШИРЕНИЯ>`. При локальной загрузке на другом устройстве ID может отличаться; добавь каждый разрешённый ID через запятую. Для стабильного общего ID пакет нужно подписывать одним и тем же ключом Chrome при упаковке.
6. Запусти API и HTTPS-прокси:

   ```bash
   docker compose up -d --build
   docker compose ps
   ```

7. Проверь `https://<твой-домен>/health`. Caddy получит и будет продлевать TLS-сертификат автоматически. Если сертификат не выдан, проверь DNS и доступность портов 80/443.
8. В расширении укажи `https://<твой-домен>`, создай кабинет с кодом приглашения и задай отдельный мастер-пароль снимка.

Не отправляй коды, пароли и cookie в чат. Секреты генерируй непосредственно на VPS; доступ к `.env` оставь только администратору (`chmod 600 .env`).

## Ежедневное использование

1. На исходном устройстве вручную войди в Google, VK и СДО РТУ МИРЭА и заверши их проверки.
2. В расширении войди в свой кабинет, выбери сайты, задай мастер-пароль и нажми **Сохранить текущие сессии**.
3. На другом устройстве загрузи расширение, укажи тот же адрес API, войди в тот же кабинет и нажми **Войти везде**.
4. На чужом/общем устройстве нажми очистку, чтобы удалить локальные cookie и отключить токен кабинета. Токен расширения автоматически исчезает при закрытии браузера.

Каждый кабинет имеет отдельную строку архива и отдельные серверные токены. Сервер сохраняет только зашифрованный блок; мастер-пароль не отправляется на сервер. Токен входа хранится в `chrome.storage.session` и действует до 8 часов на сервере.

## Обслуживание

Посмотреть состояние:

```bash
docker compose ps
docker compose logs --tail=100 api caddy
```

Обновить код после копирования новой версии:

```bash
docker compose up -d --build
```

Резервная копия PostgreSQL (выполнять на VPS; архив содержит зашифрованные снимки и хэши паролей):

```bash
docker compose exec -T db sh -c 'pg_dump -U "$POSTGRES_USER" "$POSTGRES_DB"' > session-workspace-backup.sql
```

Храни копию отдельно от VPS с ограниченными правами. Восстановление выполняется в пустую базу:

```bash
cat session-workspace-backup.sql | docker compose exec -T db sh -c 'psql -U "$POSTGRES_USER" "$POSTGRES_DB"'
```

## Область пилота и ограничения

- Разрешены только Google, VK и домены `mirea.ru`; расширение не собирает cookies остальных сайтов.
- Новый снимок заменяет предыдущий снимок этого же кабинета.
- Кнопка выхода чистит cookie выбранных сервисов в текущем профиле и отзывается токен кабинета на сервере. Она не гарантирует отзыв скопированной сессии на стороне Google/VK/МИРЭА.
- Пилот не включает восстановление пароля, подтверждение почты, биллинг, админ-панель и независимый аудит безопасности. Код приглашения ограничивает регистрацию закрытой группы, но не является полноценной системой управления доступом.
- Настрой резервное копирование, обновления ОС/Docker и мониторинг VPS. До реального использования протестируй каждый сервис на собственных аккаунтах и без чужих активных профилей браузера.
- Не используй это как способ обхода правил провайдера или политики учреждения; обладание cookie фактически даёт доступ к аккаунту.
