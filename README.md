# Session Workspace

Расширение Chrome/Chromium для сохранения и переноса зашифрованных браузерных сессий. Сервер уже развёрнут и работает — нужно только загрузить расширение.

## Что делает расширение

1. Вы входите в Google, VK и/или СДО РТУ МИРЭА обычным способом на исходном устройстве.
2. Расширение собирает cookie выбранных сервисов, шифрует их мастер-паролем прямо в браузере и отправляет зашифрованный блок на сервер.
3. На другом устройстве вы входите в тот же кабинет, вводите мастер-пароль — расширение скачивает блок, расшифровывает и восстанавливает cookie.
4. Переключатели в интерфейсе позволяют выбрать, в какие сервисы авторизоваться, а в какие нет. Настройки сохраняются между сессиями.

Сервер видит только зашифрованный блок — мастер-пароль никогда не покидает браузер.

## Быстрый старт — 3 шага

### Шаг 1. Загрузите расширение

1. Откройте `chrome://extensions` в Chrome/Chromium.
2. Включите режим разработчика (переключатель в правом верхнем углу).
3. Нажмите «Загрузить распакованное расширение».
4. Выберите папку проекта (где находится `manifest.json`).

### Шаг 2. Создайте кабинет

1. Нажмите на иконку расширения в панели Chrome.
2. Введите email.
3. Введите пароль кабинета (минимум 12 символов).
4. Введите код приглашения: **`afb762d18313c4cabfabc418816ff1bd`**
5. Нажмите «Создать кабинет».

### Шаг 3. Сохраните и перенесите сессии

1. Войдите в нужные сервисы (Google, VK, СДО МИРЭА) в браузере обычным способом.
2. В расширении включите переключатели только для нужных сервисов.
3. Введите мастер-пароль для шифрования (минимум 12 символов, не совпадает с паролем кабинета).
4. Нажмите «Сохранить текущие сессии».
5. На другом устройстве: загрузите расширение, войдите в кабинет, включите нужные сервисы, введите мастер-пароль и нажмите «Войти везде».

## Переключатели сервисов

В расширении есть три переключателя:

- **Google** — Google-сервисы (google.com)
- **VK** — vk.com
- **СДО РТУ МИРЭА** — online-edu.mirea.ru

Включите только те, в которые хотите войти. Остальные будут полностью пропущены. Выбор сохраняется автоматически — при следующем открытии расширения настройки останутся.

## Выход на устройстве

На чужом или общем устройстве нажмите «Очистить сессии этого устройства» — это удалит локальные cookie выбранных сервисов и отключит токен кабинета. Зашифрованный снимок на сервере сохраняется для следующего входа.

## Безопасность

- Сервер хранит только зашифрованные блоки — мастер-пароль не передаётся на сервер.
- Шифрование выполняется в браузере (AES-GCM + PBKDF2).
- Токен входа хранится в `chrome.storage.session` и действует 8 часов.
- Каждый кабинет имеет отдельный снимок и отдельные токены.

## Ограничения

- Разрешены только Google, VK и домены `mirea.ru`.
- Новый снимок заменяет предыдущий.
- Сайты могут отклонить перенос cookie или снова запросить подтверждение.
- Кнопка выхода не гарантирует отзыв скопированной сессии на стороне Google/VK/МИРЭА.
- Не используйте это как способ обхода правил провайдера или политики учреждения.
